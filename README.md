# New Vision Daycare Website

Official website for **New Vision Daycare** – A Christian-based group family daycare located in Brooklyn, New York.

## Tech Stack
- Next.js 15
- Tailwind CSS
- JavaScript
- Deployed on Vercel

## Getting Started

1. Clone the repository
2. Install dependencies:
```bash
npm install
```
3. Run the development server:
```bash
npm run dev
```
4. Open [http://localhost:3000](http://localhost:3000)

## Project Structure
- `app/` → Pages and layout
- `components/` → Reusable components (we will create these)
- `public/` → Images and static files
